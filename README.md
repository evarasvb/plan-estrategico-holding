# Espacio de trabajo compartido

Repositorio de coordinación y entregables para Ailín/GPT, Claude, Grok y Cursor.

## Empezar

1. Leer [AGENTS.md](AGENTS.md), el protocolo común.
2. Revisar los [Issues](https://github.com/evarasvb/plan-estrategico-holding/issues) y [pull requests](https://github.com/evarasvb/plan-estrategico-holding/pulls) existentes antes de iniciar un encargo.
3. Acordar objetivo, responsable y criterio de aceptación en un Issue, usando la [plantilla de tarea](tareas/PLANTILLA.md).
4. Proponer los cambios en una rama y un pull request vinculado al Issue.
5. Verificar el resultado y registrar la evidencia antes de cerrar.

## Acceso y privacidad

Este repositorio es público. Publicar únicamente material profesional expresamente autorizado para difusión pública. No incorporar datos de clientes, información privada, credenciales, tokens ni conversaciones.

Esta estructura no conecta por sí sola a ninguna IA. Cada participante debe verificar su acceso de lectura y, cuando corresponda, de escritura. No hay sincronización automática ni procesos de ejecución programados.

El contenido anterior fue sustituido en la versión actual para dedicar este repositorio al trabajo compartido. El historial Git se conserva: las versiones anteriores siguen siendo recuperables y públicas. Este cambio no constituye una eliminación de su historial.
