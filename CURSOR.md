# Cursor

Leer y seguir [AGENTS.md](AGENTS.md), que contiene el protocolo compartido y es la única fuente de reglas de colaboración de este repositorio.

Consultar [README.md](README.md) para el índice y [tareas/README.md](tareas/README.md) para encargos y estados.

Cursor trabaja sobre el código y los archivos del repositorio: abrir el repo en Cursor, crear una rama por encargo (`tarea/<numero>-<descripcion-breve>`) y proponer los cambios por pull request vinculado al Issue.

La existencia de este archivo no acredita acceso de Cursor. Verificar lectura y capacidad de contribución antes de anunciar resultados. Si el acceso es solo de lectura, indicarlo y entregar propuestas por el canal autorizado, sin afirmar que se publicaron.
